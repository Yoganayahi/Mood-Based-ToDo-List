Mood-Based To-Do List

A modern and interactive Mood-Based To-Do List Web Application built using HTML, CSS, and JavaScript.

This application helps users organize and manage tasks based on their mood, making productivity more engaging and personalized.

🌟 Features
🎯 Add and manage tasks easily
😊 Mood-based task categorization
📅 Due date management
✅ Mark tasks as completed
↩️ Undo completed tasks
🗑️ Delete tasks
🌙 Dark Mode / ☀️ Light Mode
💾 Local Storage support
📱 Responsive User Interface

🛠️ Technologies Used
HTML5
CSS3
JavaScript
Local Storage API
