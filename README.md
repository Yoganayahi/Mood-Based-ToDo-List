Mood-Based To-Do List

A modern Mood-Based To-Do List Web Application built using HTML, CSS, and JavaScript.

Features:
Welcome Page
Add Tasks
Mood Selection
Due Date Management
Complete / Undo Tasks
Delete Tasks
Dark Mode
Local Storage Support
Responsive Design

Technologies Used:
HTML5
CSS3
JavaScript
Local Storage API
